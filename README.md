# Netflix Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on a Netflix dataset using Python.

The objective is to analyze the Netflix content library, identify patterns and trends, and generate meaningful insights through data analysis and visualization.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Project Workflow

1. Import required libraries
2. Load the Netflix dataset
3. Understand the dataset
4. Data cleaning and preprocessing
5. Exploratory Data Analysis
6. Data visualization
7. Identify important patterns and insights
8. Draw conclusions

## 📁 Project Files

| File                                 | Description                              |
| ------------------------------------ | ---------------------------------------- |
| `Netflix_EDA_Capstone_Project.ipynb` | Complete EDA analysis and visualizations |
| `Netflix_Dataset.csv`                | Dataset used for the analysis            |
| `requirements.txt`                   | Required Python libraries                |

## 🎯 Objective

The main objective of this project is to understand the Netflix dataset and use Python-based data analysis and visualization techniques to discover useful insights.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Install the required libraries:

```bash
pip install -r requirements.txt
```

3. Open the Jupyter Notebook:

```bash
jupyter notebook
```

4. Open `Netflix_EDA_Capstone_Project.ipynb`.
5. Run the cells sequentially.
